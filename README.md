#Superstore Sales & Profitability Analysis#

This project analyses the Superstore retail dataset to answer practical business questions about growth, profitability and discounting. The raw data was normalised in MySQL into a star schema (a fact table with customer segment, location, product and shipping dimensions), then validated against the source table to confirm row counts and totals matched.

Using SQL, the analysis covers year-on-year growth and seasonality, category and sub-category performance, loss-making products, the effect of discounts on margin, regional and state results, customer segments, shipping performance, and customer concentration and retention. Each finding includes the number, what it means, and a recommendation.

Tools: MySQL, MySQL Workbench
Skills shown: data modelling, data validation, SQL joins and aggregations, business-focused analysis
